# ✦ Things I've built

## 🧠 CodeMentor

An interactive, IDE-like environment designed to make learning Python more intuitive.

Instead of simply running code, CodeMentor helps users **understand what their code is doing**.

**What it includes**

- 🖥️ Interactive coding environment
- ▶️ Real-time code execution
- 🔍 Line-by-line execution
- 💡 Explanations of code and its purpose
- 🤖 AI-assisted Python learning
- 💻 Interactive terminal
- 🐳 Docker-based execution environment

**Built with:** React · Node.js · Docker · AI


## 📊 Algorific

An interactive learning platform focused on **Data Structures**, using visualization and interactive elements to make concepts easier to understand.

The idea is simple:

> **Don't just read about how something works. See it happen.**

**Includes**

- Interactive visual learning
- Concept explanations
- Algorithm visualization
- Educational interactions and games

**Built with:** JavaScript · React


## 🛰️ Automated Slum Classification

A research project exploring automated classification of informal settlements using **Deep Convolutional Neural Networks and K-means clustering**.

The system works with high-resolution satellite imagery and combines:

`CNNs` → `K-means` → `GDAL` → `QGIS`

to classify different land-use patterns across the **Mumbai Metropolitan Region**.

The work was presented at **ICATES 2025** and published in the **IET Conference Proceedings**.

**Research focus:** Remote Sensing · Deep Learning · Computer Vision · GIS
